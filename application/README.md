## EfficiencyAttack

`EfficiencyAttack/application` 中包括五个应用：

- `amber_alert`
- `animal`
- `expressway`
- `smart_home`
- `traffic`


### 下载模型

运行前先从网页 https://drive.google.com/drive/folders/1YtrqwWbi3qfu0wJ6BX1nvMHJPBQMkM_m?usp=drive_link 下载模型，替代文件夹 `EfficiencyAttack/application/model`

## 配置参数

在各个应用文件夹目录下，`configs.py` 文件中调整 `method` 参数，更换输入图片路径

## 运行代码

在各个应用文件夹目录下，执行 `python3 pipeline.py`
